# ITMO Deep Learning

Homework repository for the third-year Deep Learning course at ITMO.

## Submission workflow

Each homework is submitted as a pull request from a dedicated branch (`hw-1`, `hw-2`, etc.) into `main`. Review feedback stays in the corresponding pull request.

Homework files are organized under `homeworks/hw-N/`. Each submission includes the completed notebook with outputs, assignment dependencies, and required artifacts.

Datasets and local environment files are excluded from version control.
